Preprocessing

Persiapan dan transformasi data sebelum proses analisis.

  • Pembentukan skor perilaku berdasarkan indikator perilaku siswa.
  • Penentuan kategori nilai semester, kehadiran, dan ekstrakurikuler.
  • Penentuan label prestasi siswa menjadi Tinggi, Sedang, atau Rendah.

Split Data

Pembagian dataset menggunakan rasio 70:30 dengan random state 42.

Dataset dibagi menjadi dua bagian, yaitu 70% data training dan 30% data testing. Data training digunakan untuk melatih model Categorical Naive Bayes, sedangkan data testing digunakan untuk mengevaluasi kemampuan model dalam melakukan klasifikasi.
